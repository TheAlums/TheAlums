# The Alums

College players after they leave. Domain: thealums.com

Upload **this folder** as the Cloudflare Pages root (the folder that contains `index.html`, `producks/`, `_redirects`).

## After deploy

- `thealums.com` network home
- `thealums.com/producks` Oregon desk
- `thealums.com/producks/herbert` player file (via `_redirects`)
- `www` → apex is in `_redirects`; also set a Cloudflare redirect rule if needed

Fantasy is merged into Stats. CFL is a filter chip on Players and Stats.
